# 行业解决方案速查

> 本文档提供6大行业的IT咨询核心关注点, 快速定位行业特定问题和解决方案方向。

---

## 1. 金融服务业 (银行/保险/证券)

### 行业核心挑战
- 核心系统遗产化: 大型机/Cobol, 维护成本高, 人才断层
- 监管合规压力: Basel IV/DORA/国家金融监督管理总局（2023年由银保监会改组，已于2026-07更正）&人行&网信办
- 开放金融: API经济, 嵌入式金融, 生态竞争
- 安全要求极高: 零容忍, 实时风控

### IT咨询重点领域
| 领域 | 典型问题 | 解决方案方向 |
|------|---------|-------------|
| 核心银行现代化 | 大型机→云原生, 怎么迁移不掉数据 | 绞杀者模式(Strangler Fig), 逐步替换 |
| 实时风控 | 低延迟反欺诈/反洗钱（示例口径：决策链路 P99 ≤ 50ms，服务端测量） | 流计算+AI+图数据库 |
| 智能客服 | 客服量大, 标准化高 | NLP+RAG+Agent, 自动化率70-90% |
| 开放银行 | API标准化/安全/治理 | API Gateway + OAuth2.0 + 开发者门户 |
| 合规科技 | 监管报告手工, 出错率高 | 自动化数据采集+AI审计+实时合规监控 |

### 关键指标
- 核心系统可用性 > 99.99%
- 交易处理延迟 < 50ms (P99)
- 实时风控误报率 < 5%
- 监管报告自动化率 > 90%

## 2. 制造业/工业4.0

### 行业核心挑战
- OT/IT融合: 工控系统与IT系统数据孤岛
- 产能可见性差: 不知机器什么时候会停
- 供应链韧性: 全球供应链波动
- 产品同质化: 从卖产品→卖服务转型

### IT咨询重点领域
| 领域 | 典型问题 | 解决方案方向 |
|------|---------|-------------|
| 工业互联网 | 设备数据采集/协议繁杂 | IIoT平台 + 边缘计算 + 数据标准化 |
| 预测性维护 | 定期维护成本高/意外停机 | IoT传感器+ML时序预测 |
| 数字孪生 | 设计-生产-运维数据不打通 | 统一数据平台+3D建模+仿真 |
| 智能制造 | MES/WMS/SCADA各一套, 数据不通 | 统一制造数据平台+API集成层 |
| 供应链数字孪生 | 不知供应链断在哪/影响多大 | 供应链可视化+AI预测+what-if仿真 |

### 关键指标
- OEE提升 > 15%
- 非计划停机减少 > 30%
- 质量缺陷率降低 > 25%

## 3. 零售与消费品

### IT咨询重点领域
| 领域 | 典型问题 | 解决方案方向 |
|------|---------|-------------|
| 全渠道中台 | 线上/线下/分销数据割裂 | OMS+CRM+CDP+Loyalty中台 |
| AI精准营销 | 营销ROI不清晰 | CDP+AI推荐+动态定价 |
| 智能供应链 | 库存高但缺货率也高 | 需求预测AI+智能补货+仓储自动化 |
| 门店数字化 | 门店客流/转化无数据 | IoT+CV+智能导购 |
| 私域运营 | 公域流量贵, 私域转化差 | 企业微信+小程序+SCRM |

### 关键指标
- 线上转化率提升 > 20%
- 库存周转天数降低 > 15%
- 营销ROI提升 > 30%

## 4. 医疗健康

### IT咨询重点领域
| 领域 | 典型问题 | 解决方案方向 |
|------|---------|-------------|
| 医院信息化 | HIS/CIS/LIS/PACS各一套, 互不联通 | ESB集成总线+HL7/FHIR标准 |
| 互联网医院 | 线上诊疗/处方/支付一体化 | 微服务架构+安全合规 |
| AI辅助诊断 | 影像/病理大夫工作量大 | AI医学影像+CDSS |
| 数据合规 | 健康数据是敏感个人信息 | 分级分类+脱敏+审计追踪 |
| 互联互通 | 不同医院病历不互通 | 互联互通成熟度评估(V4/V5)+平台建设 |

## 5. 政府与公共服务

### 政策背景: 数字中国2025
- "数据要素×"三年行动计划: 数据资产入表
- 信创替代: 2027年党政+央企核心系统全栈替代
- 全国一体化政务大数据体系: 2025年初步建成
- 三大工程: 一网通办/一网统管/一网协同

### IT咨询重点领域
| 领域 | 典型问题 | 解决方案方向 |
|------|---------|-------------|
| 数字政府 | 各部门系统独立建设 | 政务云/大数据平台/统一身份认证 |
| 一网通办 | 群众办事多头跑 | 业务流程再造+数据共享+电子证照 |
| 智慧城市 | 烟囱式建设, 数据不通 | 城市大脑+IOC+数据中台 |
| 信创替代 | 国外产品有安全隐患 | CPU/OS/DB/中间件/应用全栈国产化 |
| 政务AI | 审批效率低 | 智能审批/政策推演/城市治理AI |
| 信创替代 | 国外产品安全隐患+合规风险 | 全栈国产化+分区分批+双轨运行 |
| 数据资产入表 | 数据价值无法体现 | 确权→评估→入表→交易 |
