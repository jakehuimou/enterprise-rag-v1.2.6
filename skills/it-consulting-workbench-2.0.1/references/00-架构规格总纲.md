# 架构规格总纲 · IT 咨询顾问超级工作台（V2.0.0）

> 本工作台不是"写完即过期的静态知识库"，而是一套**零人为干预自迭代的活体专家系统**。
> 它靠四根支柱立住：**交叉引用网 · 检索驱动保鲜 · 严谨性闸门 · 自迭代引擎**。
> 任何一份交付物，过不了闸门，不出稿。

---

## 0. 一句话定位

让一个新手 IT 顾问，用上这个 Skill，也能交出**顶级咨询公司水准的交付物**：
从 IT 战略规划到企业架构、从技术尽调到供应商选型、从 TCO / ROI 商业论证到变革落地与高管汇报——
全链路覆盖（8 阶段 35 个工作流），且每一份产出都**可溯源 · 可复核 · 可保鲜**。

---

## 1. 四支柱总览

| 支柱 | 解决什么 | 本库落地方式 |
|---|---|---|
| ① 交叉引用网 | 文件孤岛、信息矛盾、找不到入口 | 每份文件 `related` 双向互链 + 文末「下一步去哪」导航 + 引擎机检 0 断链 |
| ② 检索驱动保鲜 | 云价格 / 咨询费率 / 合规标准快速过时 | `:::dynamic-hook` 动态钩子 + [新鲜度账本](../data/02-新鲜度账本.md) 登记 + 季度刷新 |
| ③ 严谨性闸门 | 幻觉、过度承诺、口径不清 | G1–G12 静态闸 + DG1–DG6 动态闸 + AI 对抗共识总闸 |
| ④ 自迭代引擎 | 人工维护不可持续 | 七步流水线 · 哈希链审计 · 黄金问答自愈 · 专家理事会 |

## 2. 支柱一：交叉引用网（Cross-Reference Mesh）

**规则**
- 每份 `.md` 必须含 `related:` 字段，列出 2 个以上真实存在的文件（仓库根相对路径）。
- 文末必须含 `## 下一步去哪`，提供 ≥2 条出边链接。
- 正文相对链接必须以**当前文件所在目录**为基准（同目录直接写文件名；跨目录用 `../`）。
- 引擎 `--check-mesh` / `--fix-mesh` 校验双向可达与孤岛；`--check-all` 的 S-05/S-06/S-07/S-11/S-12 守护此网。

**为什么**：0 基础用户不该被"多套编号体系"逼疯。一个总纲 + 一张网，牵着人走完 8 个阶段。

## 3. 支柱二：检索驱动保鲜（Retrieval-Driven Freshness）

**动态钩子格式**
```
:::dynamic-hook
id: DH-IT-EXAMPLE-FORMAT
target: 主流公有云关键资源（计算 / 存储 / 出网流量）的现行单价区间
authority_tier: T1
retrievability: R1
retrieval: 云厂商官方定价页 与 第三方比价平台交叉
dual_source: 必需（至少 2 个独立公开来源交叉，单源不得单独支撑结论）
cache_ttl: 90d
fallback: 若无法核验，标注〔未核验·使用 2026-08-14 快照值〕，且该数值禁止写入对客交付物的承诺性章节
verify: 比对报价"生效日期"与取数日期一致，且明确口径（地域 / 规格 / 计费模式 / 折扣类型）
output_req: 必须携带字段：资源名、规格、单价区间、币种、地域、生效日期、来源 CH
owner_gate: DG2, DG3, DG5, G5
:::
```

**约束**
- `id` 全局唯一，格式 `DH-[A-Z0-9-]+`；两个文件不得复用同一 id（引擎 S-10 拦截）。
- `volatility` 三档：`static`（慢变，如方法论、企业架构框架）/ `hybrid`（半变，如成熟度模型、组织设计）/ `dynamic`（快变，如云单价、咨询费率、合规标准版本）。
- 慢变内容走「静态核心 + 动态层」混合；快变内容走保鲜引擎（账本登记 + 定期重算）。
- [新鲜度账本](../data/02-新鲜度账本.md) 由 `--sync-ledger` 自动重建，记录每个钩子的上次核验时间与来源。

**诚实边界红线**：绝不宣称"永远最新/最强"，只宣称**可溯源 · 可复核 · 可保鲜**。

## 4. 支柱三：严谨性闸门（Rigor Gates）

### 4.1 静态闸 G1–G12（每次交付物必过）

| 编号 | 闸门 | IT 咨询语义 | 机检信号 |
|---|---|---|---|
| G1 | 结论可溯源 | 现状判断须标注证据来源（访谈 / 系统盘点 / 日志 / 财务台账），不得"拍脑袋" | related 含来源文件 |
| G2 | 指标可量化 | 技术与业务指标须可测（可用性 / MTTR / 变更失败率 / 单位交易成本），并定义口径 | 指标附口径说明 |
| G3 | 决策留痕 ADR | 技术选型、自建 vs 采购、云迁移 6R 路径等单向门须记 ADR | 引用 [架构规格总纲](00-架构规格总纲.md) 的 ADR 约定 |
| G4 | 权衡显式化 | 性能—成本—安全—交付速度的四角权衡须显式，不得只报好处 | 含"权衡"段 |
| G5 | 成本 / ROI 可复算 | TCO 五年模型、ROI / NPV / IRR 须可复算，附假设与敏感性 | 引用 [TCO分析模板](../templates/TCO分析模板.md) |
| G6 | 风险与反证 | 技术 / 实施 / 组织 / 供应商风险须列反证与失败模式 | 含"风险"段 |
| G7 | 合规核验 | 数据合规、网络安全等级保护、行业监管要求须核验现行版本 | 引用 [安全战略与风险管理](../workflows/03-战略与方案设计/06-安全战略与风险管理.md) |
| G8 | 图文一致性 | 架构图 / 拓扑图与文字描述一致，不画"看起来对"的图 | 图下有说明 |
| G9 | 用户语言分层 | 给董事会 / 业务方 / IT 团队 / 供应商的语言不同（SCQA vs 技术规格） | 分层陈述 |
| G10 | 路线图可行 | 实施路线含里程碑、依赖、资源与退出条件，不画大饼 | 含里程碑 |
| G11 | 数据隐私 | 数据分级、PII、跨境传输、脱敏方案须核验 | 引用 [数据战略与治理](../workflows/03-战略与方案设计/05-数据战略与治理.md) |
| G12 | 版本失效 | 引用的标准 / 框架版本须标注现行状态，禁用已废止版本 | 标注版本状态 |

### 4.2 动态闸 DG1–DG6（发布前 / 季度刷新必过）

- **DG1 钩子时效**：所有 `:::dynamic-hook` 的 `last_verified` 距今天 ≤ `cache_ttl`，否则告警。
- **DG2 来源可达**：钩子 `retrieval` 入口可访问（或标注"需人工核验"）。
- **DG3 口径一致**：同一指标在全文口径一致（如"TCO 边界"不漂移：是否含人力、含机会成本）。
- **DG4 反证齐全**：每个强结论须有至少一个反证 / 失败模式。
- **DG5 合规现行**：引用的法规 / 标准为现行有效版本（非废止版本）。
- **DG6 成本可复算**：投资 / TCO / ROI 数字可逆向复算到假设。

### 4.3 AI 对抗共识总闸（总出口）

每份交付物在出稿前，须过**对抗共识门**：
- 至少 1 个"红队"视角对结论发起攻击；
- 多源共识度 `N` ≥ 2（独立来源相互印证）；
- 置信度 `C = 0.35×T + 0.25×A + 0.20×F + 0.20×R` ≥ 0.6（T 权威 / A 一致 / F 可复算 / R 可检索）；
- 硬不变量 HI-1~HI-8 零触发（见 [硬不变量清单](../data/03-硬不变量清单.md)）。

## 6. 支柱四：零人为干预自迭代引擎（Self-Iterating Engine）

入口：`scripts/self_iterate.py`（Python 3，零第三方依赖）。

**七步流水线**
1. 探针采集（`--probe`）：从 [权威来源渠道地图](../data/01-权威来源渠道地图.md) 抓取权威源。
2. 语义扫描（`--scan`）：跑 [语义一致性扫描规则](../data/05-语义一致性扫描规则.md) 的 N/T/F/X 规则。
3. 哈希链审计（`--verify-chain` / `--anchor-chain`）：`this_hash = SHA-256(prev_hash + "\n" + body)`，首条 `prev_hash` = 64 个 0。
4. 交叉引用网校验（`--check-mesh` / `--fix-mesh`）。
5. 黄金问答自测（`--golden`）：[黄金问答自测集](../data/04-黄金问答自测集.md) 的 GQ-01~GQ-12 判据集。
6. 账本同步（`--sync-ledger`）：重建 [新鲜度账本](../data/02-新鲜度账本.md)。
7. 快照与回滚（`--snapshot` / `--rollback`）：存 `backups/`，异常可回滚。

**自迭代六件套**：对抗共识门 / 专家理事会(4 Agent) / 哈希链审计(SHA-256) / 语义一致性扫描 / 黄金问答自愈合回滚 / Meta-Loop 过程自进化。

**自治等级**：L0 人工触发 → L3 零人为干预；月度 RRULE + 事件双触发；`isolation/`、`backups/` 非阻塞。隔离区登记见 [隔离区账本](../data/09-隔离区账本.md)。
