## 案例C01：全球供应链数字化转型战略规划

> **真实案例来源**：Dell Technologies全球供应链数字化转型，源自MIT CTL Digital Supply Chain Transformation Lab的公开案例研究（Sáenz, Borrella & Revilla），Ivey Publishing 2024/2025年度最畅销运营管理案例。

### 项目背景

**客户**：某全球科技制造企业，年营收超800亿美元，供应链覆盖全球50+国家、300+供应商、20+制造基地（*注：客户画像基于Dell Technologies公开资料抽象，具体访谈内容为基于行业实践推断*）

**触发事件**：全球供应链复杂度指数级增长——SKU数量增长3倍、订单碎片化、地缘政治扰动频繁，传统人工决策模式已无法应对E2E协同需求。供应链计划团队每天花费60%+时间在数据收集与手工协调上。

**项目目标**：设计并实施AI驱动的E2E供应链编排体系，实现从"人工决策→自动化执行→智能编排"的跃迁。

### 阶段0：商机开发与签约

**初次沟通纪要（SCQA框架）**：

| SCQA | 内容 |
|------|------|
| **S (Situation)** | 全球供应链运营基数庞大——年均采购额数百亿美元，但供应链计划与执行之间存在显著断点，计划数据到现场执行平均延迟48小时 |
| **C (Complication)** | 关键零件（如硬盘驱动器）短缺频发，季度缺货损失超千万美元；老化库存占比持续攀升，占用营运资金；竞争对手已部署AI排程和数字孪生 |
| **Q (Question)** | 如何构建AI驱动的E2E供应链编排能力，在3年内实现从"被动响应"到"自主决策"的范式转换？ |
| **A (Answer)** | 三阶段路线：先"看得见"（E2E数据集成与可视化），再"算得准"（AI预测与智能排程），最后"动得快"（自主编排与闭环自愈） |

**项目建议书核心章节**（9章标准结构）：

1. 项目理解：当供应链复杂度超过人脑处理极限——全球50+国家、300+供应商、百万级SKU组合
2. 方法论：MECE五维诊断 + AIM²成熟度模型 + MIT DSCT（Digital Supply Chain Transformation）框架
3. 工作范围：现状诊断 → 能力蓝图设计 → AI编排平台架构 → 路线图规划 → 速赢验证
4. 团队配置：项目总监1人 + 供应链架构师2人 + AI/ML专家2人 + 变革管理专家1人 + 数据工程师2人
5. 时间计划：16周（诊断4周 + 蓝图设计4周 + 平台架构3周 + 路线图2周 + 速赢POC 3周）
6. 交付物：诊断报告 + DSCT能力蓝图 + AI编排平台架构设计 + 3年路线图 + 速赢POC报告
7. 费用：520万（含差旅与POC原型开发）
8. 团队资质：MIT CTL供应链数字化研究项目核心成员，服务过3家Fortune 500科技制造企业
9. 下一步：签约后2周内启动诊断

### 阶段1：项目启动与诊断

**IT/供应链现状五维诊断（MECE）**：

| 维度 | 现状评分 | 关键发现 |
|------|:---:|------|
| **技术** | 2/5 | 遗留系统30+个、数据孤岛严重、无统一数据湖、AI/ML基础设施处于试点阶段 |
| **流程** | 2/5 | 需求预测靠Excel+经验、供应商协同靠邮件/电话、异常处理平均需跨6个部门协调 |
| **组织** | 2/5 | 计划/采购/物流/制造各自为政，无E2E供应链可视化角色，数据科学团队仅5人 |
| **数据** | 1/5 | 主数据质量差（物料主数据准确率仅78%）、供应商数据缺失率40%、无统一数据治理 |
| **财务** | 2/5 | 库存持有成本年化超20亿美元、缺货损失年化约3亿美元、IT预算中供应链占比仅12% |

**AIM² AI成熟度评估**：

| 层级 | 描述 | 当前状态 | 目标（3年） |
|:---:|------|:---:|:---:|
| L1 初始 | 规则驱动，无AI能力 | | |
| L2 探索 | 试点AI预测、异常检测 | ✅ 当前 | 已完成 |
| L3 规模化 | AI嵌入E2E编排核心流程 | | 第1年末 |
| L4 优化 | AI自主决策+人机协同 | | 第2年末 |
| L5 领先 | AI Native供应链，自愈闭环 | | 第3年末 |

**干系人访谈（四波法）**（*注：以下访谈内容为基于行业实践推断*）：

| 波次 | 对象 | 核心发现 |
|:---:|------|----------|
| 第1波 | SVP Global Supply Chain / CFO | "供应链复杂度每年增长20%，但我们的决策速度没变。我们需要AI让5000个日常决策自动化，让人聚焦在50个战略决策上" |
| 第2波 | 计划VP / 采购VP / 物流VP | "硬盘短缺那次我们花了三周才完成供需重新匹配，如果AI能把这个时间压到小时级，我们的竞争力完全不同" |
| 第3波 | 区域计划经理 / 供应商管理经理 | "每天花4小时拉数据、做表格、发邮件协调。预测偏差累积到执行端，牛鞭效应放大了3倍" |
| 第4波 | IT/数据平台团队 | "我们有数据，但分散在30+系统里。我们需要一个统一的数据底座和编排引擎" |

### 阶段2：战略与方案设计

**供应链数字化转型战略（Run/Grow/Transform模型）**：

| 类别 | 预算占比 | 核心项目 | 预期价值 |
|------|:---:|------|------|
| **Run** (运营) | 30% | 统一数据底座（Data Lakehouse）、主数据治理、API集成网关 | 数据可及性从48小时→实时，主数据准确率从78%→95% |
| **Grow** (增长) | 40% | AI需求预测、智能库存优化、供应商风险预警 | 预测准确率提升5-15%、老化库存减少50% |
| **Transform** (转型) | 30% | E2E AI编排引擎、数字孪生沙盘、自主决策Agent | 季度自动化5000+行动、决策速度提升2倍、生产力提升40%+ |

**3年路线图**：

| 年份 | 主题 | 核心项目 | 关键里程碑 |
|:---:|------|------|------|
| 第1年 | 数据基础+AI预测 | 统一数据底座建设、主数据治理、AI需求预测模型部署、供应商风险雷达 | Q2数据底座上线、Q4 AI预测模型覆盖80% SKU |
| 第2年 | E2E编排+智能库存 | AI编排引擎V1（计划→采购→制造→物流）、智能库存优化、硬盘供应链专项 | Q2编排引擎覆盖3条核心产品线、Q4硬盘零件短缺减少77% |
| 第3年 | 自主决策+数字孪生 | 编排引擎V2（自主决策+人机协同）、数字孪生沙盘、全球推广 | Q2自主决策覆盖60%常规场景、Q4全球所有区域推广完成 |

**速赢项目（Quick Wins）**：

| 速赢项目 | 投入 | 时间 | 预期效果 |
|----------|:---:|:---:|------|
| 硬盘供应链AI预警 | 200万 | 3个月 | 硬盘零件短缺减少77%（基于真实案例数据） |
| 老化库存AI识别与动态促销 | 150万 | 2个月 | 老化库存首批减少25% |
| E2E可视化看板 | 100万 | 2个月 | 替代手工日报，供应链状态实时可见 |

**ROI分析（基于Dell真实成效推算）**：

|----------|------|:---:|:---:|
| 库存持有成本降低（老化库存-50%） | 年库存成本~200亿 | 0.5-1.0% | 100-200 |
| 缺货损失减少（硬盘短缺-77%） | 年缺货损失~3亿 | 77% | ~230 |

**ROI**：投资回收期 < 12个月，5年NPV（折现率8%）= 15-22亿美元，IRR > 150%

### 阶段5：变革管理

**ADKAR变革模型应用**：

| 阶段 | 行动 |
|------|------|
| **Awareness** (认知) | 全球供应链SVP全员信 + "AI不是替代你，是让你从5000个日常决策中解放出来"愿景沟通 |
| **Desire** (意愿) | 速赢项目让计划团队先感受价值——硬盘短缺预警让团队从"救火"变为"防火" |
| **Knowledge** (知识) | 三层培训体系：高管AI战略工作坊、计划员AI协作操作培训、数据团队MLOps技术培训 |
| **Ability** (能力) | 设立"供应链AI编排运营中心"，每区域配1名AI供应链BP（Business Partner） |
| **Reinforcement** (巩固) | 月度自动化行动量看板、季度E2E指标复盘（预测准确率、库存健康度、决策延迟） |

### 经验教训

1. **AI编排不是技术项目，是运营模式变革**：Dell案例证明，真正的价值不在算法本身，而在将AI嵌入E2E决策闭环
2. **速赢要选"痛中之痛"**：硬盘短缺是Dell供应链的"阿喀琉斯之踵"，77%的改善不仅省了钱，更赢得组织对AI转型的信心
3. **五维诊断揭示根因**：技术评分2/5的背后是组织2/5和数据1/5——先治数据和组织，技术才能发挥作用
4. **Run/Grow/Transform让预算分配有战略逻辑**：30/40/30的分割既保障了日常运营不被颠覆，又为变革留出充足弹药
5. **AIM²渐进路线打消"AI万能论"**：L2→L3→L4的每阶段都有可量化KPI，让董事会看到每一步的投资回报

## 案例C02：Agentic AI企业软件商业模式尽调

> **真实案例来源**：明略科技（2718.HK）2025年年度财报及公开报道，明略科技于2025年11月3日在港交所主板上市，被称为"全球Agentic AI第一股"。客户名称及访谈内容为基于行业实践推断。

### 项目背景

**客户**：某TMT领域头部PE基金（管理规模超500亿元，示例数据，已脱敏），计划对一家中国AI企业软件公司进行Pre-IPO轮投资决策（*注：标的公司画像基于明略科技公开资料抽象*）

**尽调目标**：评估标的公司的技术能力（Agentic AI技术栈）、商业模式创新性（RaaS vs SaaS）、财务健康度、组织效率、竞争壁垒

**时间要求**：4周内完成技术与商业尽调报告

### 四维尽调框架

#### 维度1：技术与AI能力评估

**AI技术栈评估**：

| 评估项 | 发现 | 评级 |
|--------|------|:---:|
| 自主模型能力 | 自研Cito推理模型（BFCL小模型榜#1）、Mano GUI-VLA模型（OS-World榜#2、Mind2Web榜#1），13个评测SOTA | ✅ 领先 |
| Agent平台 | 自研多Agent开源协作平台Octo，内部部署2900+ Agent，1400名员工使用 | ✅ 领先 |
| 企业级AI底座 | DeepMiner平台——"调度-决策-执行"多智能体分层架构，全链路AI自动完成率90% | ✅ 良好 |
| 数据资产 | 秒针系统覆盖中国90%+互联网广告流量监测，近20年数据积累 | ✅ 领先 |
| 开源策略 | Mano-P调用Skill与端侧模型已开源，Octo平台开源 | ✅ 良好 |
| AI Native硬件 | 首款AI Native硬件Octic（会议场景），标志软硬一体延伸 | ⚠️ 早期 |
| 专利储备 | 2400+项专利 | ✅ 领先 |

**AI能力评分**：8.5/10

#### 维度2：商业模式与财务质量

**商业模式分析——从SaaS到RaaS**：

| 评估项 | 发现 | 评级 |
|--------|------|:---:|
| 核心定价模型 | 从传统SaaS（按席位/功能模块收费）→ RaaS/Agentic Services（按可量化业务结果收费） | ✅ 创新 |
| Agentic Services收入 | 首年（2025年）收入突破1亿元人民币（示例数据，已脱敏），占总收入7%，新增大客户中30%+来自该板块 | ✅ 高增长 |
| 毛利率 | 55.4%，同比提升3.8pct，反映AI对交付成本的系统性压缩 | ✅ 改善中 |
| 大客户续约率 | 96%，核心客户群稳定 | ✅ 优秀 |
| 总收入 | 14.26亿元（示例数据，已脱敏），同比+3.2%（表面温和，但结构性变化显著） | ⚠️ 温和增长 |
| 经调整净利润 | 4204万元（示例数据，已脱敏），实现扭亏为盈（2024年同期-4511万元） | ✅ 拐点 |
| 研发费用趋势 | 2022年7.51亿→2024年3.53亿，降幅53%，但代码产出增长10倍 | ✅ 效率革命 |
| 客户基础 | 135家财富世界500强、~2100家品牌客户、24万+企业用户 | ✅ 深厚 |

**关键结构性信号**：

| 指标 | 传统SaaS预期 | 明略实际表现 | 信号解读 |
|------|:---:|:---:|------|
| 研发费降53% | 竞争力衰退 | 代码产出增长10倍 | AI对研发效率的系统性重构 |
| 5人团队产出 | ~5万行/年 | 37万行有效代码 | 传统50-80人18个月的工作量 |
| 毛利增速 vs 收入增速 | 同步或略高 | 10.8% vs 3.2%（3.4倍） | 高毛利业务占比快速提升 |

**商业模式评分**：8/10

#### 维度3：组织效率与AI原生运营

**AI对组织效率的重构**（基于公开财报数据）：

| 维度 | 关键数据 | 含义 |
|------|------|------|
| 全体员工AI接入 | 100%接入DeepMiner平台 | AI不是工具部门的事，是组织操作系统 |
| 营销智能交付效率 | 最高提升4倍 | 同样的人力，4倍产出 |
| 营运智能工单 | 解决时间压缩超30% | 客户服务成本系统性下降 |
| 秒针系统Agentic改造 | 60天全链路贯通，AI自动完成率90% | 深度复盘报告人效提升20倍 |
| 研发"剪刀差" | 研发费-53%，代码产出+10× | AI Native研发范式验证 |

**组织效率评分**：8.5/10

#### 维度4：竞争壁垒与风险

**竞争格局评估**：

| 维度 | 评估 | 风险等级 |
|------|------|:---:|
| 行业数据护城河 | 近20年营销数据积累，覆盖90%+互联网广告流量，迁移成本极高 | 🟢 低风险 |
| 客户粘性 | 96%大客户续约率、部分大客户合作超10年，RaaS模式加深依赖 | 🟢 低风险 |
| 巨头竞争 | 华为、阿里、腾讯等均有Agentic AI布局，但明略的垂直行业Know-how+数据是差异化壁垒 | 🟡 中风险 |
| RaaS规模化风险 | 模型预测精度需持续维持，客户行业多元化可能带来边际成本波动 | 🟡 中风险 |
| 技术路线风险 | 从数据智能→Agentic AI的范式迁移，需持续保持模型领先性 | 🟡 中风险 |
| 生态依赖 | 腾讯持股~27%，既是资源也是依赖；腾讯自身广告业务扩张可能产生竞合张力 | 🟡 中风险 |
| 流通盘风险 | 次新股，上市初期实际流通盘极低（锁定期），股价波动大 | 🟡 中风险 |

**竞争壁垒评分**：7.5/10

### 技术/商业债务量化

| 债务/风险类型 | 量化估算 | 业务影响 | 优先级 |
|----------|:---:|------|:---:|

| 客户集中度风险 | 前五大客户依赖度需持续监控 | 若大客户自研替代，收入影响显著 | P1 |
| Agentic Services规模化验证 | 当前1亿收入基数小，需验证跨行业复制能力 | 增长故事的核心假设 | P1 |
| 软硬一体（Octic）投入 | 预计5000万+ | 硬件是全新领域，存在执行风险 | P2 |
| **合计** | **约2亿/年** | | |

### 尽调结论

**综合评分**：8.1/10

**投资建议**：推荐投资，建议在投资协议中约定：

1. **Agentic Services收入目标**：交割后2年内Agentic Services收入占比提升至20%+（当前7%）
2. **毛利率门槛**：维持55%+毛利率水平，验证RaaS模式可规模化
3. **大客户续约率**：维持95%+续约率，作为客户价值验证的核心KPI
4. **研发效率持续追踪**：代码产出/研发费用比率持续改善，验证AI Native研发范式
5. **估值逻辑**：采用SaaS（PS）+ Agentic Services（基于GMV/结果付费的溢价倍数）分部估值法

### 经验教训

1. **商业模式创新比技术创新更难判断**：SaaS→RaaS的切换不是产品升级，是定价权的重新定义。关键是验证"按结果收费"模式下毛利率能否维持
2. **研发费用大降不一定是坏事——看代码产出**：明略53%研发费降幅+10倍代码产出增长的"剪刀差"，是AI Native研发范式的核心信号
3. **续约率96%是最诚实的客户投票**：在SaaS行业续约率承压的大背景下，这个数字说明客户从RaaS模式中拿到了可量化的业务结果
4. **5人37万行代码是对传统软件工程的"降维打击"**：当AI把边际交付成本压缩到1/5，传统SaaS厂商的成本优势瞬间瓦解
5. **分部估值法应对商业模式切换**：SaaS基本盘用PS，Agentic Services用效果付费溢价，避免单一估值框架误判
