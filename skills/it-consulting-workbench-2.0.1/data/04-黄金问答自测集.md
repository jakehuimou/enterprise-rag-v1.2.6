# 黄金问答自测集

IT 咨询顾问的能力没法靠"写完一份建议书"自证——真正分高下的，是面对 CIO、架构师、安全官追问时答得全不全、准不准、有没有来源。
这份自测集是 12 道"高频、易翻车、可机检"的黄金问题（Golden Questions），每题给出**必含要点**（答案须至少命中其一）与**禁含内容**（答案不得出现）。
自检引擎用它做回归：任何一次产出质量改动，都必须保证这 12 题不退化。

> **判卷规则**：12 题全部命中必含要点、且零禁含 → 通过（pass_threshold=12）。任一题未命中要点或命中禁含 → 该次迭代判 fail，回滚并写入 `data/09-隔离区账本.md`。


### GQ-01｜IT 战略规划（SoR/SoD/SoI + Run/Grow/Transform）的核心要素有哪些？

**必含要点**
- `现状与能力基线（As-Is）`
- `目标架构与差距分析（To-Be / Gap）`
- `投资分类：Run（运维）/ Grow（增长）/ Transform（转型）`
- `路线图与优先级（价值×可行性）`
- `治理与度量机制`

**禁含内容**
- `只写"要上云/要数字化"不给依据`
- `无差距分析直接给方案`


### GQ-02｜如何用 TOGAF ADM 做企业架构设计？

**必含要点**
- `业务架构 / 数据架构 / 应用架构 / 技术架构 四层`
- `预备阶段与架构愿景（Phase A）`
- `机会与解决方案（Phase E）/ 迁移规划（Phase F）`
- `需求管理贯穿全生命周期`

**禁含内容**
- `只画一张图不分层`
- `跳过业务架构直接谈技术选型`


### GQ-03｜TCO 与 ROI 的区别？5 年总拥有成本应含哪些隐性成本？

**必含要点**
- `TCO = 购置 + 实施 + 运维 + 退出 的全周期成本`
- `ROI = (收益 − 成本) / 成本，需明确折现`
- `隐性成本：培训、迁移、故障停机、集成、许可续费、人员`
- `与 NPV / IRR / 回收期的关系`

**禁含内容**
- `只算软件采购价当 TCO`
- `收益无口径、成本不可复算`


### GQ-04｜云迁移 6R 框架及选型决策？

**必含要点**
- `Rehost / Replatform / Refactor / Repurchase / Retain / Retire`
- `按应用特征（耦合度、许可、数据敏感性）匹配 6R`
- `迁移波次与回滚预案`
- `与 FinOps 成本联动`

**禁含内容**
- `一律"重构上云"`
- `不评估许可与数据驻留就定 R`


### GQ-05｜AI 转型成熟度（AIM² L1-L5）如何评估？

**必含要点**
- `L1 初始 → L5 优化 五级定义`
- `评估维度：战略、数据、模型、组织、治理`
- `用例优先级用 RICE+ 或价值×可行`
- `与业务 KPI 对齐`

**禁含内容**
- `只买模型不谈数据与治理`
- `用"AI 赋能"等空话替代成熟度判据`


### GQ-06｜技术尽调（架构/代码/安全/团队）四个维度？

**必含要点**
- `架构：可扩展性、技术债、关键依赖`
- `代码：质量、测试覆盖、可维护性`
- `安全：漏洞、合规、密钥管理`
- `团队：关键人风险、知识密度`

**禁含内容**
- `只看演示不给技术债结论`
- `不区分"能跑"与"能规模化和运维"`


### GQ-07｜网络安全与零信任（NIST CSF 2.0）核心？

**必含要点**
- `识别 / 防护 / 检测 / 响应 / 恢复（ + 治理 ）`
- `零信任：从不信任、持续验证`
- `与等保 2.0 / ISO 27001 的映射`
- `数据分类分级与最小权限`

**禁含内容**
- `只堆设备清单不说控制目标`
- `宣称"已合规"而不给测评结论出处`


### GQ-08｜数据战略与治理（Data Mesh / Lakehouse / MDM）？

**必含要点**
- `数据域所有权（Data Mesh 范式）`
- `湖仓一体（Lakehouse）架构取舍`
- `主数据管理（MDM）与指标口径统一`
- `数据质量与血缘`

**禁含内容**
- `只建平台不谈治理与ownership`
- `指标口径不唯一导致"同数不同源"`


### GQ-09｜供应商评估与选型（评分→演示→PoC→参考调查）？

**必含要点**
- `评分卡维度：功能/架构/生态/服务/总拥有成本`
- `演示验证关键场景而非 PPT`
- `PoC 明确验收标准与数据`
- `参考调查验证真实交付与运维`

**禁含内容**
- `只看厂商宣传不验证`
- `选型结论无依据与评分记录`


### GQ-10｜变革管理（ADKAR + Kotter）与 IT 组织设计？

**必含要点**
- `ADKAR：认知/渴望/知识/能力/巩固`
- `Kotter 八步：紧迫感→愿景→赋能→短期胜利`
- `平台型 + 产品型组织模式`
- `采用度仪表盘`

**禁含内容**
- `只推工具不谈人的转变`
- `忽视变革疲劳与阻力来源`


### GQ-11｜FinOps 三阶段与云成本优化？

**必含要点**
- `Inform（可见）/ Optimize（优化）/ Operate（运营）`
- `单位经济（如每订单成本）而非只看总账`
- `闲置资源、预留实例、标签治理`
- `与工程绩效（DORA）联动`

**禁含内容**
- `只做账单分摊不优化`
- `成本数字无业务口径`


### GQ-12｜高管汇报（SCQA + 金字塔原理 + 30 秒结论）？

**必含要点**
- `结论先行（30 秒给出核心建议）`
- `SCQA：情境/冲突/问题/答案 叙事`
- `金字塔：结论→论据→数据支撑`
- `风险与下一步明确`

**禁含内容**
- `从头铺陈无结论`
- `用堆砌细节替代决策建议`
