# 新鲜度账本

商业分析里最危险的错误不是"写错"，而是"曾经对、现在错"——一份半年前援引的行业基准、一个去年谈妥的咨询费率，静默过期后继续出现在新商业论证里。
这份账本把"哪些快变数值需要周期性重取、何时到期、最近一次取数在哪天"集中登记，让自检引擎（`scripts/self_iterate.py`）能逐行探测并报警，避免过期快照混进对客承诺。

> **定位**：本文件是"快变数值"的单一真相源（Single Source of Truth）。`data/01-权威来源渠道地图.md` 决定去哪查，本账本决定查到的值还新不新。
