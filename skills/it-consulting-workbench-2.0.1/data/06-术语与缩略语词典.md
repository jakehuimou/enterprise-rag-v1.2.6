# 术语与缩略语词典（Glossary）

> IT 咨询全库统一术语。正文用词须与本文一致；歧义词以本文为准。机检 T 类规则以 [语义一致性扫描规则](05-语义一致性扫描规则.md) 为真源。

## A–B
- **ADR**：Architecture Decision Record / 架构决策记录。单向门决策必须留痕（G3）。
- **ADKAR**：Awareness-Desire-Knowledge-Ability-Reinforcement 个体变革模型。
- **APM**：Application Performance Monitoring / 应用性能监控。
- **AIM²**：本库 AI 转型场景筛选框架（价值×可行性双轴，见核心方法论库）。
- **BPM**：Business Process Management / 业务流程管理。
- **Business Case**：商业论证，回答"为什么值得投"（含 TCO / ROI / 风险 / 备选方案）。

## C–F
- **CMDB**：Configuration Management Database / 配置管理数据库。
- **CMMI / CMMM**：能力成熟度模型集成 / 智能制造能力成熟度模型。
- **交付物**：本库统一术语，指 IT 咨询顾问产出的文档 / 模型 / 清单（不称"输出物"）。
- **DORA 四指标**：部署频率 / 变更前置时间 / 变更失败率 / 服务恢复时间（MTTR）。
- **Data Mesh**：数据网格，域自治 + 数据即产品 + 自助平台 + 联邦治理。
- **DACI**：Driver-Approver-Contributor-Informed 决策模型。
- **等级保护**：网络安全等级保护制度，正式章节用全称并注明简称（T-09）。
- **动态钩子**：`:::dynamic-hook` 标记的快变数值实取声明（不称"检索钩子"，T-05）。
- **EA**：Enterprise Architecture / 企业架构。
- **FinOps**：云财务运营，云成本可见—可控—可优化的组织实践。
- **FR / NFR**：功能需求 / 非功能需求（NFR 为统一写法，T-01）。

## G–K
- **Gate / 闸门**：交付物出稿前必过的校验点（统一用"闸门"，T-07）。
- **硬不变量（HI）**：不可违反的诚实红线，编号 HI-1~HI-8（不用"硬约束/铁律"作编号替身，T-06）。
- **IRR**：Internal Rate of Return / 内部收益率。
- **ITIL**：IT 服务管理最佳实践框架。
- **信创**：信息技术应用创新，正文展开一次后统一用简称（T-08）。
- **KPI / OKR**：关键绩效指标 / 目标与关键结果。

## M–R
- **MTTR / MTBF**：平均恢复时间 / 平均无故障时间。
- **NPV**：Net Present Value / 净现值。
- **NIST CSF**：美国 NIST 网络安全框架（引用须标注现行版本，G12）。
- **PoC / Pilot**：概念验证 / 试点，二者验证目标与退出条件不同。
- **RACI**：Responsible / Accountable / Consulted / Informed 职责分配。
- **RFI / RFP / RFQ**：信息征询 / 需求建议书 / 报价征询。
- **ROI**：Return on Investment / 投资回报率，须可复算到假设（G5）。
- **6R**：Retire / Retain / Rehost / Replatform / Refactor / Repurchase 云迁移路径分类。

## S–Z
- **SCQA**：Situation-Complication-Question-Answer 高管汇报结构。
- **SLA / SLO / SLI**：服务等级协议 / 目标 / 指标，须明确测量口径（G2）。
- **SoR / SoD / SoI**：记录型 / 差异化 / 创新型系统（Pace-Layered 分层）。
- **SOW**：Statement of Work / 工作说明书。
- **SteerCo**：Steering Committee / 项目指导委员会。
- **TCO**：Total Cost of Ownership / 总拥有成本，须声明成本边界（是否含人力、机会成本）。
- **TOGAF**：The Open Group 企业架构框架（引用须标注现行版本）。
- **置信度**：量化语境下对结论把握程度的评分（不用"可信度/把握度"作替身，T-10）。
- **Run / Grow / Transform**：IT 投资三分类（维持运营 / 支撑增长 / 驱动转型）。
