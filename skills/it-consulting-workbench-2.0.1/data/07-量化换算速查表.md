# 量化换算速查表（含动态钩子）

> 快变数值一律走 `:::dynamic-hook` 实取，绝不静默写死。本表由 `scripts/self_iterate.py --sync-ledger` 联动 `data/02` 账本。
> 所有数值均为〔示例快照·待核验〕，落地前以钩子 `probe` 入口复核。

## 1. IT 行业经营基准（示例快照 · 2026-08-14）

:::dynamic-hook
id: DH-IT-INDUSTRY-BENCHMARK
target: 主流 IT / 软件行业关键经营基准（研发投入占比 / 云支出增速 / 人效）的最新区间
authority_tier: T2
retrievability: R1
retrieval: 国家统计局年度公报 与 行业上市公司年报双源交叉
dual_source: 必需（至少 2 个独立公开来源交叉，单源不得单独支撑结论）
cache_ttl: 180d
fallback: 若无法核验，标注〔未核验·使用 2026-08-14 快照值〕，且该数值禁止写入对客交付物的承诺性章节
verify: 比对数据"报告期"与取数日期一致，且明确行业分类口径
output_req: 必须携带字段：指标名、区间、口径说明、来源 CH、生效日期
owner_gate: DG2, DG3, DG4, G2
:::

- 示例：软件/SaaS 行业研发投入占营收中位数约 15–25%；全球企业云支出年增速约 15–20%（均为公开年报/报告区间，非承诺值）。

## 2. 折现与货币时间价值

| 参数 | 口径 |
|---|---|
| NPV | 折现率建议取 WACC（8%–12% 示例区间），期限 3–5 年 |
| IRR | 与资本成本比较，>WACC 视为可行（示例，需按企业口径） |
| 回收期 | 静态 ≤ 2 年、动态 ≤ 3 年通常较优（行业而异） |

## 3. IT 咨询与实施费率（示例快照 · 2026-08-14）

:::dynamic-hook
id: DH-IT-CONSULTING-RATE
target: 顶级 IT / 管理咨询与实施项目费率（人天）的现行基准区间
authority_tier: T2
retrievability: R1
retrieval: 第三方薪酬报告（Mercer / 科锐）与公开招标中标价双源交叉
dual_source: 必需（薪酬报告 + 公开中标价交叉）
cache_ttl: 180d
fallback: 若无法核验，标注〔未核验·使用 2026-08-14 快照值〕，且该数值禁止写入对客报价单与合同
verify: 比对报告"报告期"与取数日期一致，区分国内/海外与顾问级别
output_req: 必须携带字段：级别、计费单位、单价区间、币种、生效日期、来源 CH
owner_gate: DG2, DG3, DG4, G2
:::

- 示例：资深顾问 8k–20k 元/人天，合伙人级 30k–80k 元/人天（示例区间，非报价）。

## 4. 主流云厂商算力/存储单价（示例快照 · 2026-08-14）

:::dynamic-hook
id: DH-IT-CLOUD-PRICING
target: 主流公有云（计算/对象存储/出口带宽）现行单价区间
authority_tier: T2
retrievability: R1
retrieval: 各云厂商官网定价页 与 云成本报告双源交叉
dual_source: 必需（厂商定价 + 独立成本基准交叉）
cache_ttl: 90d
fallback: 若无法核验，标注〔未核验·使用 2026-08-14 快照值〕，且禁止写入客户报价单
verify: 核对计费模式（按需/预留/竞价）与区域，明确币种
output_req: 必须携带字段：资源类型、单价区间、计费单位、区域、币种、来源 CH
owner_gate: DG2, DG3, DG4, G2
:::

- 示例：通用计算按需约 0.3–1.5 元/核·小时区间，对象存储约 0.08–0.15 元/GB·月（示例，以官网实时定价为准）。

## 5. IT 合规标准时效

:::dynamic-hook
id: DH-IT-COMPLIANCE-STANDARD
target: IT 咨询涉及的中国数据 / 网络安全 / 密码合规法规现行有效版本号
authority_tier: T1
retrievability: R1
retrieval: 全国人大法规库 与 网信办 / 公安部 / 国家密码管理局规章库
dual_source: 必需（立法机关 + 监管部门双源）
cache_ttl: 365d
fallback: 若无法核验，标注〔未核验·以发布机关最新公报为准〕，且禁止写入"已合规"结论
verify: 核对标准号与生效日期，确认未被废止或修订
output_req: 必须携带字段：标准号、名称、生效日期、发布机关、状态
owner_gate: DG5, G7
:::

- 关注：网络安全等级保护 2.0（GB/T 22239）、ISO/IEC 27001、数据安全法、个人信息保护法及配套规章现行版本。
