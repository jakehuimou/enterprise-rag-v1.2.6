# 权威来源渠道地图（Freshness Sources）

> 检索驱动保鲜的"取水口"。所有 `:::dynamic-hook` 必须从下表取源，且**至少 2 个独立源交叉**。
> 单源不得单独支撑对客交付物中的承诺性结论。

## 1. 标准与认证机构（T1 最高权威）

| 来源 | 覆盖 | 取数方式 |
|---|---|---|
| IIBA 官网（BABOK v3 / Guide to Business Data Analytics） | 全球 BA 知识体系 | 官方出版物 + 会员库 |
| PMI（PMI-PBA / PMBOK） | 商业分析过程 / 项目管理 | 标准文档 |
| BCS（英国计算机学会 BA 认证） | 业务分析实践 | 官方大纲 |
| 国家标准委 / 国家数据局 | 中国数据 / 治理合规 | 政府公报 |

## 2. 行业与宏观数据（T2）

| 来源 | 覆盖 |
|---|---|
| 国家统计局年度公报 / 国民经济和社会发展统计公报 | 宏观经营基准 |
| 行业上市公司 annual report（巨潮 / 公司 IR） | 行业净利率 / 人效 |
| 麦肯锡 / BCG / 贝恩 公开研究 | 方法论与基准 |
| 第三方薪酬 / 费率报告（如 Mercer / 科锐） | 咨询费率 |

## 3. 法规与监管（T1，须现行有效）

| 来源 | 覆盖 |
|---|---|
| 全国人大 / 国务院条例 | 反垄断 / 数据安全 |
| 网信办 / 工信部规章 | 数据出境 / 个人信息 |
| 财政部会计准则 | 财务核算口径 |

## 4. 取数纪律

- 快变数据（行业基准 / 费率）：`cache_ttl` ≤ 180d，季度核验。
- 法规标准：引用时标注版本号与生效日期（DG5）。
- 任何来源失效或废止，立即在 `data/02-新鲜度账本.md` 标注，并在正文打〔已废止〕。
