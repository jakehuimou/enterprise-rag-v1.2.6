# 角色职责矩阵（IT Consulting Role Matrix）

> 对应 IT 咨询全场景的 8 类核心角色。每个角色负责不同闸门，协作时以 RACI 对齐。

| 角色 | 核心交付物 | 主责闸门 | 协作对象 |
|---|---|---|---|
| CIO / 信息化负责人 | IT 战略规划 / 投资优先级 | G1 / G2 | 高管、董事会 |
| 企业架构师（EA） | 企业架构蓝图 / 标准规范 | G1 / G3 | 各域架构师、治理委 |
| 解决方案架构师（SA） | 方案设计 / 技术选型论证 | G3 / G8 | 研发、产品、售前 |
| IT 咨询顾问 | 诊断报告 / 建议书 / 路线图 | G1 / G2 / G5 | 业务方、管理层 |
| 项目经理 / PMO | 实施计划 / 治理报告 | G9 / G10 | 供应商、干系人 |
| 业务分析师（IT 侧） | 需求规格 / 用户故事 | G1 / G3 | 业务方、SA |
| 安全架构师 / 安全顾问 | 安全战略 / 风险评估 | G3 / G7 | 合规、运维、EA |
| 数据架构师 / 数据治理 | 数据战略 / 指标体系 | G2 / G11 | 业务、BI、法务 |

## 与专家理事会映射
- CIO / 企业架构师 / 咨询顾问 → 分析严谨官
- 安全架构师 / 财务相关 → 财务审计官
- 业务分析师 / 咨询顾问 → 业务代言人
- 解决方案架构师 / 数据架构师 → 红队攻击手（偏可行性反证）
