# 阶段3: 技术评估与选型

## 本阶段目标
帮助客户系统性地评估技术方案或选择供应商，降低采购风险，确保技术投资回报。

## 完整流程
```
需求定义 → 市场扫描 → RFP/RFI编写与发送 → 供应商演示评估 → PoC验证 → 决策推荐
```

## 前置条件
- 明确的技术/业务需求清单
- 项目预算范围(至少量级)
- 决策流程和关键决策人已识别

## 本阶段产出物
| 产出物 | 说明 | 交付对象 |
|--------|------|---------|
| 技术尽调报告 | 目标公司/系统的技术健康度评估 | 投资方/管理层 |
| RFP/RFI文档 | 标准化需求建议书 | 潜在供应商 |
| 供应商评分卡 | 加权多维度评分矩阵 | 选型决策委员会 |
| 选型推荐报告 | 含分析/决策/风险/谈判建议 | 最终决策人 |

## 关键成功因素
- **需求先行，技术后选**: 不清楚自己要什么就去看供应商，必定被带偏
- **演示脚本你来写，不要供应商写**: 基于"必赢场景"设计演示脚本，杜绝花哨Demo
- **参考电话必须打**: 至少3家同行客户参考，问题是提前准备的结构化清单
- **TCO必须包含退出成本**: 迁移到新系统/供应商的代价是TCO的一部分
