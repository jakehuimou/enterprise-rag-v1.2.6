# 变革准备度评估工具 (Change Readiness Assessment Tool)

> 使用说明: 在项目启动时和关键里程碑前, 用这个工具评估组织对即将到来的变革的准备程度。得分=发现风险的早期信号, 不是判断"能不能做",而是判断"需要在哪方面多花精力"。

---

### 评分标准
每个维度 1(完全没有准备) — 5(完全准备好了)

## 得分解读

| 得分 | 评级 | 解读 | 建议 |
|------|------|------|------|
| 4.5 - 5.0 | ✅ 绿色 | 组织已准备好 | 按计划推进, 保持当前的领导支持和沟通节奏 |
| 3.5 - 4.4 | 🟡 黄灯 | 基本准备好, 但有薄弱环节 | 针对得分最低的维度制定强化计划, 每2周重评 |
| 2.5 - 3.4 | 🟠 橙色 | 准备不足, 风险较高 | 推迟重大变革动作, 先投入2-3个月解决准备度问题 |
| 1.0 - 2.4 | 🔴 红色 | 组织尚未准备好 | 如果强行推进=高概率失败; 需要从建立紧迫感和领导对齐开始 |

## 第三部分: 按维度的具体行动

针对得分低于3的维度, 立即制定改进计划:

| 低分维度 | 当前得分 | 目标得分 | 具体行动 | 负责人 | 期限 |
|---------|---------|---------|---------|--------|------|
| [如: 信任与历史] | 2.0 | 3.5 | 1. 做一个小的Quick Win项目证明"这次不一样" | PM | 2个月 |
| | | | 2. 让之前成功项目的受益者现身说法 | 变革Lead | 1个月 |
| | | | 3. CEO公开承认过去的问题并说明为什么这次不同 | Sponsor | 2周内 |

---

## 第四部分: 重评计划

变革准备度是动态的, 不是评估一次就完了:

| 评估节点 | 时间 | 预期得分变化 | 关键观察 |
|---------|------|-----------|---------|
| 基线评估 | 项目启动前 | [__] | — |
| 第2次评估 | 项目启动后1月 | [__] | 沟通是否有效? 领导承诺是否在行动上体现? |
| 第3次评估 | 首次发布/试点前 | [__] | 早期采用者的反馈? |
| 第4次评估 | 全面上线前 | [__] | 准备度是否达标(>3.5)? |
| 第5次评估 | 上线后3月 | [__] | 变革是否被采用和巩固? |

---

## 使用场景

- **项目启动前**: 判断变革的起点, 决定是否需要先投入时间提高准备度
- **关键决策点**: 如是否进入下一阶段, 用准备度数据支撑
- **遇到阻力时**: 重新评估, 看哪个维度的准备度下降了
- **项目复盘**: 对比初始和最终准备度, 总结"什么样的变革在这个组织中最能成功"

---

## 关键提醒

1. 这不是打分后就放一边的练习 — 低分维度必须有具体的改进行动
2. 评估时要诚实 — 自我欺骗=为项目失败埋下伏笔
3. 多角色评估 — 让Sponsor/PM/业务代表/一线代表分别打分, 看分歧在哪
4. 趋势比分更重要 — 从2.5上升到3.5比一直停留在4.0更有价值
5. 这个工具评估的是"准备度", 不是"值不值得做" — 得分为2不代表不做, 代表需要先在准备度上投资
