# SteerCo月度评审模板 (Monthly Steering Committee Review)

> 使用说明: 这是IT项目月度指导委员会的标准汇报模板。每页一个核心信息, 总页数控制在10页以内, 汇报时长15-20分钟。核心原则: 说进展 + 说问题 + 说决策需求, 不念流水账。

## SteerCo汇报技巧

**会前:**
- [ ] 提前2天发材料, 让成员有时间预习
- [ ] 与Sponsor单独预沟通(不要在SteerCo上"突袭"Sponsor)
- [ ] 准备Top 5可能被问到的问题

**会中:**
- [ ] 前1分钟讲完状态和结论
- [ ] 每页讲不超过2分钟
- [ ] 风险/问题诚实说, 不要粉饰
- [ ] 决策请求具体可操作(不是"请大家支持")

**会后:**
- [ ] 24小时内发出会议纪要
- [ ] 每个决策有明确的后续行动
