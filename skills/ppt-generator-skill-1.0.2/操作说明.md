# 智能 PPT 生成助手（外部技能 `pptgen`）— 操作说明

> 本说明面向**部署 / 运维人员**和**最终用户**，说明如何把该技能放到「技能卡片」上、如何在对话与面板中使用，以及如何扩展。

---

## 一、技能是什么

`ppt-generator-skill-1.0.2` 是一个**可插拔的外部技能**，存放于独立目录：

```
skills/ppt-generator-skill-1.0.2/
├── skill.yaml        # 技能元信息（注册中心据此发现并上卡片）
├── skill.py          # 处理逻辑（run(raw, model) → 生成 .pptx）
├── SKILL.md          # 原始技能设计文档（角色 / 流程 / 风格库）
├── references/       # 各风格配色与排版规范（.md）
└── scripts/          # Node(pptxgenjs) 渲染脚本（富风格变体，可选）
```

它已被接入「技能注册中心」（`web/skills_registry.py`），**无需改代码即可上卡片、可被对话 `/` 指令调用**。

---

## 二、放到技能卡片上（已完成，这里说明原理与复核）

卡片由注册中心自动扫描 `skills/<id>/skill.yaml` 生成，无需任何代码改动。

1. 确认 `skill.yaml` 关键字段正确：
   ```yaml
   id: pptgen                       # 技能唯一ID（字母/数字/下划线，2-32位）
   name: 智能 PPT 生成助手
   icon: 🎨
   tag: 办公
   command: pptgen                  # 对话指令 /pptgen
   aliases: [pmake]
   enabled: true
   handler: skill.py:run            # 处理逻辑入口
   ```
2. 启动/重启服务后，进入左侧 **🧩 技能专家** 面板：
   - 即可看到「🎨 智能 PPT 生成助手」卡片；
   - 若服务在运行期间新增/修改了技能，点面板右上角 **🔄 刷新技能** 即可热重载，**无需重启**。

> 校验清单：卡片可见、`/pptgen` 出现在对话框「/」提示菜单、点击卡片进入通用信息工作区且显示「处理逻辑：✅ 已实现」。

## 三、使用方法

### 方式 A：对话框直接调用（推荐）

在「智能问答」对话框输入 `/` 指令：

```
/pptgen 企业知识库建设方案 --pages 10 --palette tech-dark
/pptgen AI 产品发布会
/pptgen 年度总结汇报 --pages 8 --palette coral-energy --lang zh
```

- 技能会用大模型生成大纲与正文，渲染为 `.pptx` 并保存到 `data/generated_ppt/`；
- 对话返回文件路径与参数概览，可直接打开或上传到「📁 知识管理」预览。

### 方式 B：技能面板卡片

1. 进入 **🧩 技能专家** → 点击「🎨 智能 PPT 生成助手」卡片；
2. 在打开的通用工作区点 **「在对话中调用 /pptgen →」** 按钮，自动把 `/pptgen ` 填入输入框，补上主题即可发送。

### 可调参数（写在主题后，空格分隔）

| 参数 | 说明 | 默认值 / 可选值 |
|------|------|----------------|
| `--pages N` | 内容页数量 | 默认 8，范围 3–20 |
| `--palette NAME` | 配色方案 | 见下表，默认 `midnight-executive` |
| `--lang zh\|en` | 语言 | 默认 `zh` |

#### 内置配色方案

`midnight-executive`(午夜商务) · `tech-dark`(科技深空) · `coral-energy`(珊瑚活力) ·
`warm-terracotta`(暖陶简约) · `ocean-gradient`(海洋渐变) · `charcoal-minimal`(炭灰极简) ·
`teal-trust`(青绿信任) · `berry-cream`(莓果奶油) · `sage-calm`(鼠尾草静) · `cherry-bold`(樱桃大胆)

## 四、运行依赖

- **默认（Python 渲染）链路**：使用项目 `.venv` 内已安装的 `python-pptx`，**开箱即用，无需额外安装**。
- **大模型（内容生成）**：需配置智谱 API Key（左侧「⚙️ 模型设置」）。
  - 未配置 / 调用失败时，技能**自动回退到默认模板大纲**，仍然能产出一份结构完整的 PPT（不会卡死）。
- **可选（Node 富风格）链路**：若想使用 `scripts/` 下基于 `pptxgenjs` 的更丰富插画/风格模板，需自行安装：
  ```bash
  cd skills/ppt-generator-skill-1.0.2
  npm install pptxgenjs
  node scripts/generate.js --title "主题" --palette tech-dark --lang zh --output out.pptx
  ```
  （该 Node 链路独立于对话技能，适合批量/定制化生产，详见 `SKILL.md` 与 `references/`。）

## 五、风格与模板扩展

- **配色**：在 `skill.py` 的 `PALETTES` 字典追加 `名称: (主色, 辅色, 强调色, 背景, 文字)`（十六进制，不含 `#`）。
- **风格规范**：参考 `references/` 下各 `.md`（如 `MBE插画风格规范.md`、`复古卡通风格规范.md`、`7套/9套新增风格规范.md`、`配色方案.md`），按需把对应配色补进 `PALETTES` 即可在 `--palette` 中选用。
- **内容质量**：默认由大模型按主题检索/扩写；如需固定行业话术，可在 `skill.py` 的 `_build_outline_via_llm` 提示词中补充约束。

## 六、常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 卡片不显示 | `skill.yaml` 的 `id` 与已有技能冲突，或文件格式错误 | 检查 `id` 唯一且为 `字母/数字/下划线`；点「🔄 刷新技能」 |
| `/pptgen` 不在「/」菜单 | 指令被占用或技能被停用 | 确认 `command: pptgen`、`enabled: true`，刷新后重试 |
| 返回「默认模板」而非大模型内容 | 未配置智谱 Key 或网络异常 | 在「⚙️ 模型设置」配置 `ZHIPU_API_KEY` |
| 生成的 PPT 偏简单 | 用的是 Python 默认渲染 | 如需插画/复杂版式，改用 `scripts/` 的 Node 链路 |
| 文件找不到 | 路径在 `data/generated_ppt/` | 到该目录按主题名查找 `.pptx` |

---

## 七、启停 / 卸载（配置化管理）

- **停用**：编辑 `skill.yaml` 改 `enabled: false` → 刷新技能（卡片显示「已停用」，对话不可调用）。
- **删除**：在「🧩 技能专家」面板删除，或直接在 `skills/` 下删除 `ppt-generator-skill-1.0.2/` 目录 → 刷新技能。
- **新建同类技能**：面板「➕ 新增技能」填表即可自动生成 `skill.yaml` + `skill.py` 模板并热重载。

> 所有变更均**无需重启服务**（除非删除/移动了目录本身导致模块缓存异常，此时重启一次即可）。
